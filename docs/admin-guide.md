# 管理员使用手册

欢迎使用人才盘点系统！本手册将帮助管理员快速上手，掌握系统的全部功能。

---

## 1. 登录系统

### 1.1 访问地址

在浏览器中打开系统提供的访问地址，进入身份选择页面。

### 1.2 管理员登录

1. 在身份选择页面，点击「管理员登录」入口
2. 输入管理员账号和密码
3. 点击「登录」按钮进入管理后台

> 💡 首次登录后请及时修改默认密码，确保账号安全。

---

## 2. 规则集管理

### 2.1 什么是规则集

规则集是人才盘点的评分依据，定义了评分维度、子项、权重和九宫格阈值。不同的盘点批次可以使用不同版本的规则集，便于规则迭代与历史对比。

### 2.2 创建规则集

1. 进入「规则集管理」页面
2. 点击「新建规则集」按钮
3. 填写规则集名称和描述（如「2024年度总部盘点规则」）
4. 点击「确认创建」

### 2.3 配置维度与评分项

系统默认包含三大维度，每个维度下设若干评分子项：

| 维度 | 子项 | 说明 |
|------|------|------|
| 价值观匹配度 | 共创共享认同 | 是否认同公司理念，愿意共创共享 |
| | 成本利润意识 | 是否具备成本与利润意识 |
| | 主人翁与协同 | 是否有主人翁精神，善于协同 |
| 能力 | 岗位专业胜任 | 专业知识与技能是否达标 |
| | 交付质量与效率 | 工作产出的质量与效率 |
| | 问题解决 | 分析与解决问题的能力 |
| 意愿 | 主动性 | 工作主动性与担当 |
| | 成长意愿 | 自我提升与学习意愿 |
| | 稳定性与心态 | 职业稳定性与抗压心态 |

每个评分项均为 **1-5 分**，评价人需为每项打分并填写事实依据。

**配置步骤：**
1. 在规则集详情页点击「编辑维度」
2. 可调整维度名称、子项名称和说明
3. 每项设置分值范围（默认 1-5 分）
4. 保存配置

### 2.4 权重配置

系统自动计算规则支持自定义权重：

- **加权总分** = 各维度按权重加权平均（默认：能力 60% + 意愿 40%）
- **各维度均分** = 该维度下所有子项的平均分
- **价值观匹配度** = 价值观各子项均分（红线判定依据，不作为九宫格轴）

可根据实际需要调整维度权重。九宫格的横轴与纵轴维度也可在规则集中分别指定（默认横轴 = 能力、纵轴 = 意愿）。

### 2.5 九宫格阈值

九宫格分档线默认配置如下，可根据实际情况调整：

- **低分区间**：≤ 2.4 分
- **中分区间**：2.5 - 3.9 分
- **高分区间**：≥ 4.0 分

### 2.6 红线规则

价值观维度支持红线规则：**价值观任一子项得分 ≤ 1 分**，该人员自动进入「红线讨论区」，需管理层专项讨论。

### 2.7 版本管理

- 规则集支持多版本并存
- 每次发布生成新版本号，已有批次不受影响
- 可查看历史版本，不支持删除已被引用的版本

### 2.8 发布与停用

- **草稿状态**：可编辑，不可被盘点批次使用
- **已发布**：可被新建批次引用，已发布的规则集不可直接编辑
- **停用**：不再允许新建批次使用该规则集，正在进行的批次不受影响

## 3. 评价周期（批次）管理

### 3.1 创建盘点批次

1. 进入「盘点批次」页面
2. 点击「新建批次」
3. 填写批次名称（如「2024年Q4总部人才盘点」）
4. 选择关联的规则集
5. 设置盘点开始时间和结束时间
6. 点击「创建」

### 3.2 状态管理

| 状态 | 说明 |
|------|------|
| 未开始 | 批次已创建但未到开始时间，评价人不可评分 |
| 进行中 | 盘点周期内，评价人可以提交和编辑评分 |
| 已结束 | 超过结束时间，评分入口关闭，仅可查看结果 |
| 已归档 | 历史批次，数据保留不可修改 |

可手动调整批次状态，如提前关闭盘点、重新开放等。

## 4. 参评人员管理

### 4.1 手动添加

1. 进入对应批次的「参评人员」页面
2. 点击「添加人员」
3. 填写姓名、部门、岗位等信息
4. 选择对应的评价人
5. 保存

### 4.2 批量导入（Excel）

**Excel 模板字段说明：**

| 列名 | 必填 | 说明 |
|------|------|------|
| 姓名 | 是 | 参评人员姓名 |
| 部门 | 是 | 所属部门 |
| 岗位 | 否 | 岗位名称 |
| 岗位类型 | 否 | 如管理岗、专业岗、操作岗等 |
| 评价人账号 | 是 | 该人员由哪位评价人打分，填评价人登录账号 |
| 工号 | 否 | 员工工号 |
| 备注 | 否 | 其他说明信息 |

**导入步骤：**
1. 点击「批量导入」
2. 下载 Excel 模板
3. 按模板填写参评人员信息
4. 上传填好的 Excel 文件
5. 预览导入结果，确认无误后提交

> 💡 导入前请确保评价人账号已在系统中存在。

### 4.3 分配评价人

- 每位参评人员对应一位评价人
- 可在人员列表中单独调整评价人
- 支持批量更换评价人

### 4.4 编辑与删除

- 未开始评分的人员可自由编辑和删除
- 已有评分记录的人员不可删除，只能停用
- 删除操作不可撤销，请谨慎操作

## 5. 账号管理

### 5.1 评价人账号

管理员可以管理所有评价人账号：

1. 进入「账号管理」页面
2. 点击「新建账号」
3. 填写账号（建议使用姓名拼音，如 `zhang_san`）
4. 设置初始密码
5. 填写评价人姓名
6. 保存

### 5.2 初始密码规则

系统默认初始密码规则为：**姓名拼音首字母 + 123456**

例如：张三 → `zs123456`

### 5.3 停用 / 启用账号

- 停用账号后，该评价人无法登录系统
- 已提交的评分记录不受影响
- 可随时重新启用账号

### 5.4 重置密码

当评价人忘记密码时，管理员可以重置其密码：

1. 在账号列表中找到对应账号
2. 点击「重置密码」
3. 输入新密码并确认
4. 告知评价人新密码，建议首次登录后修改

## 6. 系统设置

### 6.1 显示名称自定义

可自定义系统中显示的名称，如：
- 系统标题
- 公司名称
- 页脚文案

### 6.2 API Key 管理

用于外部系统调用开放 API 接口：

1. 进入「系统设置 → API Key」
2. 点击「生成 API Key」
3. 填写 Key 名称和用途说明
4. 设置权限范围（读 / 读写）
5. 保存后请复制 Key 值，仅显示一次

> ⚠️ API Key 是重要凭证，请妥善保管，不要泄露。如怀疑泄露，请立即吊销并重新生成。

## 7. 人才地图查看

### 7.1 九宫格解读

人才地图以散点图形式展示所有参评人员在九宫格中的位置：

- **横轴**：能力均分（右高左低，默认配置，可在规则集中调整）
- **纵轴**：意愿均分（上高下低，默认配置，可在规则集中调整）

两条分档线（默认高 = 4.0、低 = 2.5）将平面切成 3×3 = 9 个格子，加上价值观红线区共 10 个人才分类：

| 分类 | 位置 | 含义 |
|------|------|------|
| 超级明星 | 高意愿 × 高能力 | 顶尖人才，重点保留与激励 |
| 绩效之星 | 高意愿 × 中能力 | 高意愿驱动良好绩效 |
| 熟练骨干 | 高意愿 × 低能力 | 经验丰富的技术能手 |
| 潜力之星 | 中意愿 × 高能力 | 有潜力，可重点培养 |
| 中坚力量 | 中意愿 × 中能力 | 团队核心骨干 |
| 稳定贡献 | 中意愿 × 低能力 | 稳定贡献的普通员工 |
| 待成长 | 低意愿 × 高能力 | 能力强但意愿待激发 |
| 待提升 | 低意愿 × 中能力 | 需关注与辅导提升 |
| 观察改善 | 低意愿 × 低能力 | 需明确改进任务 |
| 红线区 | — | 价值观任一子项 ≤ 1 分，优先处理 |

### 7.2 筛选功能

支持多维度筛选：
- 按盘点批次筛选
- 按部门筛选
- 按岗位类型筛选
- 按人才分类筛选

### 7.3 人员详情

点击九宫格中的圆点或列表中的人员，可以查看：
- 个人基本信息
- 各维度得分明细
- 评价人填写的事实依据
- 历史盘点对比

### 7.4 数据导出

支持导出盘点结果报表（Excel 格式）：
- 全部人员得分明细
- 各分类人员清单
- 部门维度汇总统计
- 九宫格分布统计

## 8. 常见问题

**Q1：评价人忘记密码怎么办？**
A：联系管理员在「账号管理」中重置密码。

**Q2：盘点批次结束后还能修改评分吗？**
A：批次结束后默认关闭评分入口。如确需修改，管理员可以手动将批次调整为「进行中」状态，修改完成后再关闭。

**Q3：可以同时进行多个盘点批次吗？**
A：可以。不同批次相互独立，可使用不同的规则集和参评人员名单。

**Q4：评价人离职了怎么办？**
A：在账号管理中停用该评价人账号，并将其名下的参评人员转移给其他评价人。

**Q5：数据安全如何保障？**
A：所有密码使用 bcrypt 加密存储，不明文保存。API 接口通过 API Key 鉴权。建议定期备份数据库。

**Q6：如何更新规则集？**
A：规则集发布后不可直接修改。可以基于已有规则集复制一个新版本，修改后发布，新建批次时选择新版本即可。
